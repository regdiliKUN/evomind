多模态摄取图片 / 音频 / 视频 / PDF
关闭后自主学习只读文字网页，与改造前一致。语音转写需要 pip install faster-whisper，平台视频解析需要 pip install yt-dlp；两者都没装时，图片仍可用视觉模型/OCR 解析，PDF 仍可读文本层。 每轮媒体数建议 1-3：一段 10 分钟的音频转写要几十秒，设太大会把一轮学习拖长。
